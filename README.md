# BluePush

नजिकैको फोनमा (BT on भए) फाइल transfer request पठाउने Android app।

## Build
GitHub मा push गर्नुहोस् → Actions ले apk artifact दिन्छ।
वा Android Studio मा खोल्नुहोस्।

## कसरी चल्छ
1. फोटो/भ्वाइस छान्नुहोस्
2. START थिच्नुहोस्
3. नजिकका फोनमा accept prompt जान्छ

## जान्नुपर्ने
- पहिलो भेटमा receiver को BT discoverable हुनुपर्छ (Settings खोल्नुहोस्)
- एक पटक भेटेपछि MAC cache हुन्छ, त्यसपछि BT on मात्र पुग्छ
- Receiver मा app चाहिँदैन
